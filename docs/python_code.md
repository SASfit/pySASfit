# Copy Python code

Every tool can copy a Python script to the clipboard that repeats what its panel calculates: the same data
files, the same settings, the same library calls. Use it to rerun a calculation without the GUI, to
document an analysis, or as the starting point for a batch script over many files.

* **Copy Python** button in the button row of each panel (next to Calculate, Solve, Reduce, Fit, …).
* **File → Copy Python code** (`Ctrl+Shift+C`) in each tool. In the launcher the File menu lists the
  entry of the tool in front.

The script stands alone. It loads the data files by their full path and passes every setting
explicitly, including the values from *Settings → Preferences* that the calculation uses: scripts do not
read the preferences file. The plot at the end runs only while `PLOT = True` (first line after the
imports).

```python
# pyINVersion: size distribution / p(r) by inversion
# Generated by pySASfit (2026-11-07 21:10) from the current settings of the panel, ...

import numpy as np
from pysasfit.inversion.io_utils import load_sas_data
...
PLOT = True   # False: calculate only

data = load_sas_data(r"C:\data\silica.dat")
...
result = run_solver('bayesian_evidence', A, I_sub, sigma, spline=None)
```

## What each tool's script does

| tool | panel | the script |
|---|---|---|
| pySASred | Reduction ("Reduce selected") | reads the raw files of the selected runs, applies the name/role corrections, the mask of the configuration (embedded, compressed), the beam centre, the beam profile (Qdev), the q bins, the normalisation and the sector; `reduce_run_1d` per run (and per SANS-LLB panel) |
| pySASred | Reduction table | the table (`ReductionTable.from_dict`), the raw files it uses, mask, beam profile and instrument per row, `reduce_row_2d` and `average` per sample row (time-series rows point by point); the selected rows, or all rows. With the focus in the table, `Ctrl+Shift+C` copies this script |
| pySASstudio | model explorer | the contributions (form factor, size distribution, structure factor, integration settings), the curve of the plot (q grid, P·S / P / S); with data sets also their files, the model of each data set and the fit as set up in the Fit panel (parameters, bounds, global parameters, links, constraints, priors, method) |
| pySLDprofile | fit panel | data, q units and range, resolution, background terms, the model (geometry, shells or B-splines, grid, regularisation, prior), r_max, and the direct or the two-step method |
| pyINVersion | solve panel | data, error model, background (fixed or fitted), kernel, r grid, resolution, solver and its options, optional Monte-Carlo errors |
| pyOZsolver | every tab | OZ solver: the `ozLib.solve` call; polydisperse tab: form factor, `GenericPolydisperseSAS`, resolution, scale, background, power law and, with loaded data and ticked parameters, the `PolydisperseFit`; RY tab: classes, consistent α, S(Q) matrices; mixture validation: the analytic references and the solver on two grids. The solver preferences are set first (`settings.reset()` then the changed values, in memory only) |
| pySASmorph | main window and anisotropic window | the curves with SLDs, weights and backgrounds, the parameters, and Correlations or (after one) Reconstruct |
| pySCAtter | model panel | the parameters that differ from the defaults, I(q), the 2D pattern; with data selected its model and the fit of the ticked parameters |
| pyTOOLbox | merge, 2D data, 1D data, HDF5 viewer, metadata lister | merge: files, grouping, cuts, method, scaling; 2D data: images with their geometry and mask, the analysis of the Averages tab; 1D data: the selected data sets the way they were made (files read, then the operations in order); viewer: the data set shown (the slice); lister: the files of the number range and the ticked entries |

Data that exist only in memory (pySASred results passed to the merge or the 1D data tool) are written into
the script as values; 2D images from memory are left out with a note: save them as files first.

The scripts are tested: for every tool the test suite runs the copied script and compares its result with
the GUI's (`tests/*/test_python_code.py`).
