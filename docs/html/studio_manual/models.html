Building models

Contributions

A model is a mixture: I(q) = Σi scalei · Ii(q) + background (+ A·q−α). Each contribution Ii is built from up to three functions.

spheres = ScatteringContribution(
    "ff_sphere", {"R": 1, "eta": 1},                       # form factor and its fixed parameters
    size_distribution="sd_LogNorm",                        # N(x) ...
    sd_params={"N": 1e-11, "s": 0.2, "p": 1, "mu": 70},
    distributed="R",                                       # ... smears the parameter R
    structure_factor="sq_HardSphere",
    sq_params={"RHS": 70, "fp": 0.2},
    approach="lma",                                        # 'monodisperse' | 'decoupling' | 'lma'
)
model = ModelFunction([spheres], background=0.1, bg_A=1e-6, bg_alpha=4.0)   # + 0.1 + A q^-alpha

part

function

role

form factor

ff_…

the shape; one of its parameters can be distributed

size distribution

sd_…

weight N(x) of that parameter; its amplitude N is the scale

structure factor

sq_…

interaction between the particles

Without a size distribution the contribution is monodisperse and multiplied by its scale. With a size distribution the scale is fixed to 1 because N is the scale.

Structure-factor approaches

With a size distribution and a structure factor the approach decides how they are combined (SASfit manual, chapter 4.1):

  • monodisperse: S(q) · ∫N P dx;

  • decoupling: ∫N P dx + (∫N F dx)²/∫N dx · (S − 1);

  • local monodisperse (lma): ∫N P S(q; RV(x)) dx.

curves = {}
for approach in ("monodisperse", "decoupling", "lma"):
    spheres.set_approach(approach)
    curves[approach] = model.intensity(q)

Background

background is a constant. The rows bg.A and bg.alpha add a power law A·q−α (α starts at 4, the Porod value); with A = 0 it is off. In the plot the background is the dashed grey line.

Integration of the size distribution

The x integral uses Gauss–Legendre nodes on the support of N(x), or SASfit’s integrators. Settings → Integration… sets the number of nodes and tolerances. Check nodes in the Fit dock compares the result for increasing node numbers and proposes the smallest sufficient one; Profile model shows where the time of one evaluation goes. See the reference.

Own functions

Python functions can be registered as plugins and then appear in the menus like SASfit’s own; see Extending studio.
