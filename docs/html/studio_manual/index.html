studio manual

The studio tools give you the model functions of SASfit (form factors, structure factors, size distributions, peaks) in Python: you can plot them, combine them into models, fit them to data and save the result. You can work interactively in the model explorer (pysasfit-explorer) or from a script. This manual is a guided tour; the complete description of every option is in the reference and the signatures are in the API pages.

  • Getting started: install, check the libraries, a first plot and a first fit.

  • The model explorer: windows and docks, parameter rows, sliders, data, saving a session.

  • Building models: mixtures, size distributions, structure factors, background, integration.

  • Fitting: bounds, constraints, priors, optimisers, global search, speed-ups.

  • SESANS and multiple scattering: SESANS data (.ses) and multiple small-angle scattering (SASfit’s transform).

  • Polarised neutrons: polarised neutrons – magnetic models and what a data set measured (I+, I−, flipper off/on, …).

  • Python ports of SASfit plugins: Python ports of SASfit C plugins and their comparison with the C code.

  • Results and export: Result tab, correlations, Excel, CSV, summary figure, size distributions.

  • Scripting: Python examples for functions, models, the fitting engine and the export.

  • Extending studio: own functions, SasView adapter, where things are found.

About the pictures and examples

The screenshots in this manual are made by tools/studio_screenshots.py from the test data set of SASfit (examples/studio/data/SASfitTestData), so they can be renewed after a change of the GUI:

python tools/studio_screenshots.py

python tools/release.py does this as one step of a release (tests, screenshots, HTML documentation, package), so the published pictures always show the current GUI.

The code examples are the scripts in examples/studio/ (01_evaluate_functions.py … 05_open_explorer.py). They are included into the pages from those files, so what you read is what runs; tests/studio/test_examples.py checks that they are valid and, when the SASfit libraries are installed, runs them.
