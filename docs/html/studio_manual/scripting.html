Scripting

The examples are in examples/studio/ and run as they are (python examples/studio/01_evaluate_functions.py). They need the SASfit libraries; the data are in examples/studio/data/.

Evaluate functions

q = np.geomspace(1e-3, 0.5, 300)

sphere = studio.function("ff_sphere")
I_sphere = sphere(q, R=50, eta=1)                      # named parameters ...
F_sphere = sphere.amplitude(q, R=50, eta=1)            # ... the scattering amplitude F(q)

hard_sphere = studio.function("sq_HardSphere")
S = hard_sphere(q, RHS=50, fp=0.3)                     # structure factor S(q)

lognorm = studio.function("sd_LogNorm")
x = np.linspace(1, 150, 400)
N = lognorm(x, N=1, s=0.2, p=1, mu=50)                 # size distribution N(x)

A SASfit error raises studio.SASfitError with SASfit’s message; function(name, errors="warn") changes that.

Build a model

See Building models and 02_mixture_model.py. The older, shorter interface Pipeline fits in one call:

from pysasfit.studio import ModelFunction, Pipeline
pipe = Pipeline()
d = pipe.add_dataset("data.dat")
m = pipe.add_model(model, dataset=d)
res = pipe.fit(m, ["0.sd.N", "0.sd.mu", "0.sd.s", "background"])
print(res.summary())

Parameter addresses are "<contribution>.<ff|sd|sq>.<name>", "scale.<i>", "background", "bg.A" and "bg.alpha".

Fit with the engine

03_fit_with_engine.py (Fitting) fits the bimodal sphere data of SASfit with bounds, a constraint and a prior and compares optimisers. FitSummary holds values, errors, covariance, χ², the fitted curves and the state of the constraints; res.text() prints them.

Reproducing SASfit

The fit of data/SASfitTestData/test.dat reproduces the parameters of SASfit’s own project file (SASfit_test.sas) to six digits; examples/studio/example_script.py does it with the Pipeline interface.
