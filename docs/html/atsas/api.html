pyATsas: API reference

Generated from the docstrings.

pyATsas core: a thin wrapper around the ATSAS command-line programs (EMBL Hamburg / BIOSAXS GmbH).

ATSAS itself must be installed and licensed; this module locates the binaries, runs them via subprocess and parses their output files into numpy arrays / dataclasses. It has no Qt dependency (the “pyATsas” panel of the launcher is pysasfit.atsas.gui).

from pysasfit.atsas import autorg, datgnom, gnom, crysol, dammif g = autorg(“lysozyme.dat”) # Guinier Rg, I(0), range, quality p = datgnom(“lysozyme.dat”, rg=g.rg) # p(r), Dmax, real-space Rg, total estimate

Covered programs:

autorg    Guinier Rg, I(0)                        (--format=ssv)
datgnom   automatic p(r), Dmax                     (GNOM .out parsed)
gnom      p(r) with a fixed Dmax, systems 0-6      (GNOM .out parsed)
datporod  --exponent --constant: flat background of the high-q tail (with fit_power_background,
          an independent fit without ATSAS, as a check)
crysol    scattering of an atomic model (+ fit); cryson for neutrons
dammif    ab-initio bead models (n parallel runs)
launch    start the interactive ATSAS programs (PRIMUS, CHROMIXS, PEAK, ...)

Platforms: Windows (native or MSYS2 Python), Linux, macOS. The installation is found automatically (find_atsas()); check it with python -m pysasfit.atsas --selftest.

Design notes

  • ATSAS output formats change between 3.x and 4.x; parsers are deliberately tolerant (header-keyword based, not line-number based).

  • Units: the programs work in the reciprocal unit of the data; lengths come out in its inverse. pySASfit curves are in 1/nm, so Rg, Dmax and r are in nm.

  • Every call returns the raw stdout/stderr and the working directory, so the files can always be inspected afterwards.

pysasfit.atsas.core.find_atsas(atsas_dir=None, refresh=False)[source]

Return the ATSAS bin directory (cached after the first call).

Search order:

1. atsas_dir argument (root or bin directory)
2. $PYATSAS_DIR, $ATSAS (and on Windows the registry value of ATSAS)
3. autorg on $PATH (Debian/RPM packages install to /usr/bin)
4. newest ATSAS-x.y.z folder in the default locations:
   Windows  C:\Program Files\ATSAS-x.y.z, %LOCALAPPDATA%\Programs
   Linux    ~/ATSAS-x.y.z, /opt, /usr/local
   macOS    ~/ATSAS-x.y.z, /Applications, ~/Applications

A Python started from a macOS GUI does not read ~/.zprofile, so step 4 matters there even if the installer configured the shell.

3D models of the ATSAS programs: bead models (DAMMIF, DAMMIN, MONSA, GASBOR, DAMAVER …), spherical-harmonics envelopes (SASHA .flm), and the SASHA run itself. No Qt here; the 3D panel is pysasfit.atsas.view3d.

Bead models

PDB (ATOM/HETATM) or mmCIF (_atom_site) files with one dummy atom per bead, coordinates in Å; the bead radius is read from the header (DAMMIN/DAMMIF: “DAM packing radius”, “Dummy atom radius” …), else half the median nearest-neighbour distance.

Envelopes

SASHA describes the particle by its boundary r(ω) = Σ_{l≤L, |m|≤l} F_lm Y_lm(ω) with complex coefficients F_lm. The layout of the .flm file is not documented. read_flm() therefore tries the plausible layouts and normalisations of Y_lm and keeps only an interpretation whose volume and Rg agree with the values SASHA writes into the same file (FlmEnvelope.check); without such a check the envelope is not drawn.

SASHA (Legacy/sasha20.exe, Windows only) is an interactive dialog program; sasha() answers its documented dialog (ATSAS 2.x manual) through stdin, keeps the transcript, and checks that the dialog went as expected.
