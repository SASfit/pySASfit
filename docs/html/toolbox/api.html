Metadata lister

HDF Metadata Lister (pyTOOLbox tab; from tools/hdf_meta_lister.py)

Reads metadata (attributes and small datasets) from HDF5 files named <instr><year>n<number>.hdf (e.g. sans2026n052752.hdf), lists the selected entries in a table, copies it to the clipboard (tab separated, ready for a spreadsheet) and saves it as Excel, CSV or plain text.

Values in the table can be edited (double-click or F2). Edited cells are highlighted and are only written into the HDF files when you press “Write changed values to HDF files” (optionally with a .bak backup).

Requirements: pip install pysasfit[gui,toolbox] (PySide6, h5py; openpyxl only for Excel export)

All settings (folder, instrument, year, number range, the list of known entries and which of them are selected) are stored in toolbox_meta_lister.json next to the pySASfit preferences file and restored at the next start (the file ~/.hdf_meta_lister.json of the stand-alone script is read once if it exists). The largest dataset still counted as metadata and the number of digits of floating-point values are in Settings -> Preferences -> pyTOOLbox.

Merging reduced curves

Merge reduced 1D curves of the different geometries (detector distances, wavelengths) of a sample, grouped by the sample name (regular expression) and any other header item (temperature, pressure, magnetic field, shear rate, …) with a tolerance.

Readers (read_curves()):

  • pySASred NXcanSAS (.h5, also the files written here, several entries per file)

  • pySASred ASCII (.dat: q, I, Idev, Qdev, σ_sys; header with metadata_json)

  • BerSANS 1D files (Type=SANSDIso, e.g. D0082130.080: q, I, dI, dq in 1/nm)

  • plain columns q, I[, dI[, dq]] (q in 1/nm unless the header says 1/Å)

  • pySASred results in memory, without a file (curve_from_reduced(); in the GUI From pySASred)

All q are handled in 1/nm. Every curve carries its header items (Curve.meta): the named items sample, SD_m, coll_m, wavelength_A, run and everything else the file holds (hdf:<path> for pySASred, Sample/Temperature etc. for BerSANS).

Merging (merge()) keeps the absolute scale of every geometry. By default (method="all") every point of every geometry is kept with its own dI and dq, sorted by q; with method="weighted" the points in an overlap are averaged with weights 1/dI² on the bins of the coarsest curve there. Each overlap is checked: the ratio of the two curves (log-log interpolation) gives a mismatch factor with its uncertainty and χ²/ndf. Scaling to a reference geometry is optional (scale_to): one factor per geometry for all groups (merge_groups(), common_scales()), a pure multiplication of I and dI. q ranges per geometry (cuts) and dropped points at the ends (drop) as BerSANS’ merge mask.

2D data

Reduced 2D scattering images for pyTOOLbox: display now, analysis later (sector and azimuthal averages, A(q) + B(q) sin²ψ decomposition, box projections, sums of several images).

An Image2D holds the image, its statistical uncertainty, the mask and the geometry (beam centre in pixels, pixel size, detector distance, wavelength), from which q, qx, qy and the azimuth ψ of every pixel follow. Frame of pySASfit (docs/conventions.md): +x horizontal, to the right in the views (which show the detector as seen looking towards the sample), +y up; ψ = 0 along +x, counter-clockwise, as in pySASred. The raw columns of SANS-I / SANS-LLB images run towards -x (column_sign = -1; pixel views are mirrored accordingly).

Sources (read_images(), image_from_reduced()):

  • pySASred 2D NXcanSAS (*_2d.h5: I, Idev, Qx, Qy, Mask, SASdetector with the beam centre)

  • other NXcanSAS 2D files with Qx, Qy (beam centre estimated from q = 0)

  • BerSANS 2D files (Type=SANSDAni, e.g. D0082130.008): no beam centre in the file; give it with Image2D.set_geometry() (pixel 7.5 mm of SANS-I by default), else pixel axes only

  • pySASred results in memory (single runs and rows of the reduction table)

Analysis of reduced 2D images (Image2D), in the spirit of GRASP and BerSANS. Every result is a Data1D (or a new image).

Averages over the valid (unmasked) pixels of each bin: I = mean of the pixel values, σ = sqrt(Σσ_j²)/n (statistical, independent pixels), x = mean of the pixel coordinate, dx = its spread.

  • radial_average() – I(q), optionally in a sector ψ0 ± Δψ (and the opposite sector)

  • azimuthal_average() – I(ψ) in a ring q1 ≤ q ≤ q2

  • box_profile() – projection on the long axis of a box through a centre, tilted by an angle

  • sin2_decomposition() – I(q, ψ) = A(q) + B(q) sin²(ψ − ψ0) per q ring (weighted least squares over the pixels); for magnetic SANS with the field along ψ0: A = nuclear (+ magnetic ∥), B = magnetic ⊥

  • sum_images() – sum or mean of images of the same detector

  • region_integral() / rocking_curve() – mean intensity in a region (q range, sector) of each image versus a header item (e.g. a rocking angle)

Angles in degrees, ψ = 0 along +x (horizontal), counter-clockwise; q in 1/nm.

Mask helpers select pixels inside shapes drawn in any of the views (pixels, qx–qy, ψ–q): pixels_in_shape().

1D data

One-dimensional data sets of pyTOOLbox: I(q) curves, azimuthal profiles I(ψ), box profiles, rocking curves, … with uncertainties, and the arithmetic of the 1D data page.

Data1D holds x, y, dy (statistical standard deviation; NaN when unknown) and dx (resolution or bin spread; zeros when unknown) with labels and units. Operations propagate the uncertainties to first order (independent data sets):

  • scalar: scale(a) (y·a), offset(c) (y + c), divide(a) (y / a)

  • two data sets: combine(a, b, op) with op “+”, “-”, “*”, “/” or “a-f*b”; b is interpolated at the x of a (log-log where both are positive, else linear; only the overlapping x range is kept)
